# דף נחיתה — ליווי אישי במסחר באופציות

דף נחיתה סטטי (קובץ HTML יחיד, ללא צורך בשרת) בהשראת העיצוב של:
- https://meidapnim.co.il/
- https://www.futures-finance.com/money-machine

## מה יש בדף
עיצוב כהה עם דגשי זהב/ירוק (Financial / Trading), טיפוגרפיה בעברית (Heebo), ומבנה עמוד בסגנון דפי מכירה:
Hero → נתונים/אמון → בעיה/הזדהות → מה כלול בתוכנית → תהליך ב-4 שלבים → אודות המאמן → המלצות → התחייבות → שאלות נפוצות → טופס יצירת קשר → פוטר עם דיסקליימר רגולטורי.

**לא נעשה שימוש בתמונות אמיתיות של אנשים** — בכל מקום שהיה אמור להיות תמונה אישית (המאמן, ממליצים) הושם placeholder ניתן לעריכה (עיגול עם ראשי תיבות / טקסט `[מקום לתמונה]`).

## מה חייבים להחליף לפני פרסום
כל טקסט בסוגריים מרובעים `[ ... ]` הוא Placeholder לעריכה, למשל:
- `[שם מלא של המאמן]`, `[X] שנות ניסיון`, תמונת פרופיל אמיתית במקום העיגול
- ההמלצות בסקציית "מה אומרים המלווים שלי" — יש להחליף בהמלצות אמיתיות עם הסכמת הלקוחות
- הנתונים בסקציית ה-Stats (מספר תלמידים, שנות ניסיון וכו')
- הדיסקליימר המשפטי/רגולטורי בתחתית העמוד — מומלץ לאמת מול עו"ד/יועץ רגולטורי, בפרט בתחום ייעוץ פיננסי

## טופס יצירת הקשר → שליחה למייל
הטופס בתחתית הדף שולח את הפרטים (שם, טלפון, אימייל, הודעה) ישירות לכתובת:

```
stikeacademy@gmail.com
```

זה נעשה באמצעות שירות חינמי בשם [FormSubmit](https://formsubmit.co/) שמעביר טפסי HTML למייל בלי צורך בשרת/Backend.

### הפעלה חד-פעמית (חובה!)
בפעם הראשונה שישלח טופס מהדף, FormSubmit ישלח מייל אימות לכתובת `stikeacademy@gmail.com`
בבקשה ללחוץ על קישור אישור ("Activate Form") — עד שלא מאשרים, שליחות נוספות לא יגיעו.
**חשוב לבצע שליחת בדיקה אחת מיד עם עליית הדף לאוויר, ולאשר את המייל.**

אם רוצים לוודא הפעלה מראש, אפשר לפתוח את הקישור:
`https://formsubmit.co/stikeacademy@gmail.com` ולעקוב אחר ההוראות שם.

### חלופות
- אפשר להחליף את הערך של `_captcha` ל-`true` כדי להפעיל קפצ'ה אנטי-ספאם.
- אפשר לחבר טופס לשירות אחר (Netlify Forms, Google Forms, שרת עצמאי וכו') על ידי שינוי ה-`action` וה-method בתגית `<form>` בקובץ `index.html`.
